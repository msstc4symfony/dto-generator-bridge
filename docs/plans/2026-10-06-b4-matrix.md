# dto-generator-bridge — этап B4: матрица версий Symfony. План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** сгенерированные мостом DTO проверены настоящими Symfony Validator и Serializer на 5.4 / 6.4 / 7.4 / 8.x; пометки «проверить в B4» спецификации сняты.

**Spec:** `docs/specs/2026-10-02-bridge-symfony-design.md` §5.4–§5.6, §6, §8.

## Global Constraints
PHP ≥ 7.4 для `src/`; тесты интеграции выполняются в CI на PHP 8.4/8.5 (задание `phpunit` стандарта); `infection.json5`, `phpunit.xml.dist`, `Makefile` — шаблоны стандарта, не меняются.

## Решения
- **Где матрица.** Задание `phpunit` стандарта уже прогоняет набор `integration` на каждой строке `symfony-versions` и фиксирует все `symfony/*` из `composer-ci.json` на версии строки. Мост объявляет `symfony-versions` 5.4 / 6.4 / 7.4 / 8 и добавляет в `composer-ci.json` `symfony/validator`, `symfony/serializer`, `symfony/property-access`, `symfony/property-info`, `doctrine/annotations` (аннотации цели 7.4 для Symfony < 7), `phpdocumentor/reflection-docblock` (типы элементов списков из PHPDoc). Отдельный workflow не нужен.
- **Тест `tests/Integration/Symfony/RealSymfonyTest`.** Генерирует фикстуру `tests/Integration/Symfony/api.yaml` настоящим генератором с мостом (режим записи, временный каталог, автозагрузка по префиксу namespace) для целей 8.2 (атрибуты), 8.0 (атрибуты без `All`) и 7.4 (аннотации; только при Symfony < 7 и установленном `doctrine/annotations`). Версия Symfony — из `Composer\InstalledVersions`, она же уходит в `extensionConfig.symfony.version`.
  - Validator: денормализация JSON-экземпляра → `validate()` → множество путей нарушений; набор «валиден / невалиден по одному ключевому слову» на каждую строку таблицы §5.1.
  - Serializer: round-trip (`SerializedName`, `Context` даты, `DiscriminatorMap`, `Ignore`, `Groups`), `date-time` с долями секунд принимается при чтении.
  - Загрузчики метаданных выбираются по наличию классов (`AttributeLoader` с 6.4, `AnnotationLoader` до 7.0), имена классов — строками с проверкой `assertInstanceOf()` на интерфейс.
- Локальный запуск — Docker (`php:8.4-cli` + composer), команда описана в `.claude/docs`.

## Решения при выполнении
- Ruling: ядро — `X::*|null` вместо `?X::*` (PhpDocExtractor 7.4 падает TypeError) и переносимый PHPDoc: `@var`/`@param`/`@return` без уточнений, уточнения — в `@phpstan-*` (PhpDocExtractor/PhpStanExtractor 5.4 принимают `non-empty-string`, `int<0, 30>` за классы). Без этого DTO не денормализуются на 5.4 — стоимость: формат PHPDoc ядра изменился (снимки обновлены).
- Ruling: тест фильтрует устаревания только из `vendor/` (Symfony 5.4 на PHP 8.5, чтение аннотаций 6.4) — шаблон `phpunit.xml.dist` превращает их в исключения.
- Ruling: 7.4 первой в `symfony-versions` — ячейка prefer-lowest берёт первую строку; 5.4.43/6.4.0 не чисты на PHP 8.4.
- Ruling: тест исключён из PHPStan 7.4 (`phpstan-baseline.neon` `excludePaths`) и проверяется отдельным `phpstan-matrix.neon` на PHP 8.4 — PHPStan 70400 читает нативный `mixed` Symfony 8 как класс; `phpstan.dist.neon` — шаблон стандарта.
- Ruling: `config.audit.abandoned: report` в `composer-ci.json` — `doctrine/annotations` заброшен, но без него не проверить аннотации цели 7.4.
- Факты B4: см. спецификацию (§5.4, §5.6, §6, §8.1); `SymfonyVersion::LATEST` = 8.1.

## Ревью high (CR-1…S-3) — исправления
- CR-1: тест пропускается без Symfony и для целей выше версии PHP — задание `minimal` (PHP 7.4) зелёное (39 пропусков).
- CR-2: ядро допускает `symfony/console`/`yaml ^8.0` (проверено вручную на PHP 8.4: golden 8.2 байт в байт); infection `^0.29 || ^0.32`.
- MA-1: `phpstan-matrix.neon` (правило `phpstan.neon` в `.gitignore` не якорное).
- MA-2: `run-matrix.sh` повторяет задание стандарта; все ячейки 5.4/6.4/7.4/8 × PHP 8.4/8.5 и prefer-lowest 7.4 зелёные.
- MA-3: устаревания из `vendor/` собираются и сверяются со списком «чужих»; нашлось устаревание Serializer 8.1 для `date-time` → мост пишет `Context(denormalizationContext: ['datetime_format' => null])` с 8.1.
- Попутно: PHP 8.5 объявил устаревшим `(int)` у float вне диапазона int — `KeywordReader::asCount()` проверяет диапазон до приведения.
- MI-1…MI-5, S-1/S-2: `is_file()` в автозагрузчике и снятие его; фикстура дополнена (`IsNull`, `Ip` v6, `GreaterThanOrEqual`, `LessThan`, `Groups`); точные списки путей; `assertSame`; warning'и о пропуске `All` на 8.0 проверяются; заметка о `excludePaths` при перегенерации baseline — в `.claude/docs`.
- Ruling: CI моста не соберётся, пока ядро не опубликовано (`msstc4php/dto-generator` из VCS без тега) — это B6.

## Повторное ревью medium — исправления
- MI-1: Ruling — `datetime_format: null` в атрибуте перекрывает формат из контекста вызова (атрибут свойства сильнее); без него Serializer 9 отвергнет доли секунд, а это валидный RFC 3339. Компромисс описан в README и §6; отключается `x-serializer-skip`; настройка — по запросу.
- MI-2: случай `a b@example.com` проверяет, что `Email` пишется с `mode: 'html5'`; шаблон аннотаций сужен до двух сообщений 6.4: `AttributeLoader` с `AnnotationReader` (тест) и «uses Doctrine Annotations to configure …» (метаданные цели 7.4 — ожидаемо, §5.5).
- MI-4: обработчик и так подписан только на `E_DEPRECATED | E_USER_DEPRECATED` — изменений не нужно.
- S-1…S-5: `INT_LIMIT = PHP_INT_MAX + 1`; порог `LOOSE_DATE_TIME_SINCE`; `run-matrix.sh` проверяет установленную линию и тег образа; «more than once».
