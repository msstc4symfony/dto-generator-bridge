# G2 — проверка `patternProperties` и `if`/`then`/`else`

**Дата:** 2026-10-12 (UTC). **Статус:** решение принято автономно; владелец попросил сделать G2 до выпусков («сделай G2
вначале»). Дополняет `2026-10-12-g-validation-keywords-design.md` (G1): механизм заявок ядра, гейт рантайма, `Subschema`
и правило «подсхему, которую нельзя проверить целиком, не пишем и предупреждаем» остаются прежними.

## 1. Рантайм (та же невыпущенная 1.1)

- `IfThenElse(array $if = [], array $then = [], array $else = [])` — на свойстве и на классе. Значение подходит под
  `if`, когда отдельная проверка (`validate()` вне контекста, как элемент в `Contains`) не дала нарушений; тогда в
  контекст проверяются `then`, иначе `else`. `null` пропускается, как всеми constraint'ами Symfony. Ветки хранятся как
  внутренний композит `Conjunction` (`Composite::getCompositeOption()` до Symfony 7.3 возвращает одну строку), и
  вложенные constraint'ы обязаны быть во всех группах (иначе `if` выполнялся бы по части схемы).
- `Property(string $name, array $constraints)` — на классе: значение свойства (через `(array)`-приведение, общий с
  `DependentRequired` внутренний `PropertyKey`) проверяется в контексте по пути `name`; отсутствующее (`null`,
  неинициализированное) пропускается, как `properties` JSON Schema.
- `Present(array $properties)` — на классе: каждое отсутствующее свойство — нарушение по его пути
  («This field is missing.», как у `Collection`).
- `PatternProperty(string $pattern, array $constraints)` — повторяемый, только массив: значение каждого ключа
  (`(string)`), совпавшего с PCRE-шаблоном, проверяется по пути `[ключ]`. Неверный шаблон —
  `ConstraintDefinitionException`.

## 2. Мост

- `CLAIMED_KEYWORDS` += `patternProperties`, `if`, `then`, `else`. `if` без `then`/`else` и `then`/`else` без `if` в том
  же месте не действуют (JSON Schema) — место отмечается молча.
- `Subschema` принимает ещё значения enum (только `type`, `const`, `enum` и аннотации: остальные слова к PHP-enum не
  применить) и `mixed`: один тип JSON (`string`, `integer`, `number`, `boolean`, можно с `null`) даёт `Assert\Type` и
  строит прочие слова для этого типа; без `type` или с `array`/`object` — предупреждение. `enum` на PHP-enum пишется
  `Choice` из констант случаев, если сужает список случаев (и на самом свойстве тоже: прежнее предупреждение
  «One "enum" narrows another» заменяется проверкой).
- `if`/`then`/`else` у значения (свойство, элементы списка, значения map) — `IfThenElse` из трёх подсхем; значение
  скаляр, enum или `mixed`. У класса — `IfThenElse` на классе из подсхем объекта: только `properties` (каждая —
  подсхема свойства его типа, `Property`) и `required` (`Present`), плюс аннотации. Имена — проводные, переводятся в
  PHP-имена своих свойств. Свойство с default под `properties` любой ветки или в `if.required` — предупреждение (DTO не
  отличит отсутствие от default), условие не пишется. Наследование — как у `dependentRequired`: условие, все имена
  которого объявляет схема места, остаётся родителю; иначе предупреждение.
- `patternProperties`: на map — `PatternProperty` для каждого шаблона каждого места. На классе — объявленные свойства,
  чьи проводные имена совпадают с шаблоном при генерации, получают constraint'ы подсхемы (группы класса, как `Keys`);
  `$additionalProperties` — `PatternProperty`; без `$additionalProperties` — предупреждение (необъявленные свойства не
  хранятся). Рядом со схемой `additionalProperties` — предупреждение: сгенерированный тип даёт её всем необъявленным
  свойствам, в том числе совпавшим.
- Шаблон, который PHP не выполнит (`Pattern::toPcre()`), — предупреждение, шаблон не проверяется.
- Вложенные в `All` новые композиты (`IfThenElse`, `PatternProperty`) получают группы свойства; `Property` внутри
  `IfThenElse` — группы класса.

## 3. Вне рамок

- `additionalProperties: false` рядом с `patternProperties` (ключи вне шаблонов) — без изменений.
- Подсхемы с `$ref`, вложенными объектами, `allOf` и прочими составными словами внутри веток и шаблонов.
- Булева схема `false` у свойства в ветке (свойство должно отсутствовать).
- Различие `null` и отсутствующего ключа (как в G1).

## 4. Тестирование

- Рантайм: настоящий валидатор 5.4–8, аннотации (Doctrine), группы, повторный вход (вложенные `IfThenElse`), Infection
  100 %.
- Мост: эмиссия, предупреждения, отметки ядра, группы, PHP 8.0 без `new`, аннотации для 7.4; `RealSymfonyTest` с
  условием на классе и `patternProperties`; матрица 5.4/6.4/7.4/8; Infection 100 %.
